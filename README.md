# Личный дневник — веб‑приложение на Django

## Описание

Веб‑приложение для ведения личного дневника с аутентификацией пользователей, управлением записями и поиском. Реализовано на Django с использованием PostgreSQL, Bootstrap и Docker.

## Технические требования
Язык программирования: Python 3.11+

Фреймворк: Django

База данных: PostgreSQL

Шаблоны: Django Templates

Стилизация: Bootstrap 5

Контейнеризация: Docker

## Использование

```

Функционал

1. Аутентификация пользователей:

Регистрация нового пользователя

Вход в систему

Выход из системы

Защита маршрутов (только для авторизованных)

2. Управление записями дневника:

Создание новой записи (заголовок, текст, дата)

Просмотр списка своих записей

Детальный просмотр записи

Редактирование своей записи

Удаление своей записи

3. Поиск по записям:

Поиск по заголовку или содержимому (частичное совпадение)

Отображение результатов в виде списка

```
